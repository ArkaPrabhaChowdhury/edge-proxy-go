# Security Policy

## Supported versions

Only the latest tagged release is considered supported.

## Reporting a vulnerability

Please do not open a public GitHub issue for security-sensitive bugs.

Report the issue privately to the maintainer with:

- a short description of the impact
- steps to reproduce
- affected version or commit
- any suggested fix or mitigation

If a fix is confirmed, ship the patch in the next tagged release and document the change in the release notes.
